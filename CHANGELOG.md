# Changelog

## v0.1.0-preview.1 — release draft

First Windows preview of Pro Yakyuu Spirits 3 Recomp.

- Windows execution through ReXGlue and Direct3D 12.
- English and original Japanese modes, with English selected by default in the launcher.
- Separate save profiles for each language.
- Broad English interface, gameplay, management and player-creation coverage.
- English for all 940 populated fields in the known 187-event Pennant resource.
- 2,098 localized interface labels across 263 atlases.
- Team-ID-specific compact names, bounded English text handling and improved player-name coverage.
- Original Japanese stadium presentation, logos and credits preserved.

Localization, rare mode paths and live layout verification remain in progress. See [known issues](docs/known-issues.md).
