# Pro Yakyuu Spirits 3 Recomp

Windows x64 preview with English and original Japanese modes.

## Start playing

1. Extract the complete ZIP to a writable folder.
2. Open **ProSpi3 Launcher.exe**.
3. Choose your own extracted Japanese Xbox 360 game folder, containing `default.xex` and `cdvdroot/baseball.fbd`.
4. Select **English** or **Japanese**, then **Play**. English is selected by default.

The original game executable and archive are not included. First-time English setup prepares a separate archive and verifies it. Original files remain unchanged. Saves are separate for each language.

## Requirements

- Windows x64 with Direct3D 12 support.
- .NET Framework 4.8.
- The [Microsoft Visual C++ x64 Runtime](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).
- Your own supported game dump and space for the generated English files.

Python, Visual Studio and the ReXGlue SDK are not required to play this package.

## Preview status

Localization and mode testing remain in progress. Start with 720p and native rendering scale. The 2× and 3× rendering scales are experimental; DLSS/FSR-style upscaling and a verified high-frame-rate mode are not included.
